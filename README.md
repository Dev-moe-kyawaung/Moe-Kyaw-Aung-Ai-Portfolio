## 🚀 Overview

Cinematic, AI-powered, dark-minimal developer portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Features glassmorphism design, micro-interactions, project-forward case studies, and a multilingual AI assistant.

**Live Demo:** [https://moekyawaung.dev](https://moekyawaung.dev)

---

## ✨ Features

- **Cinematic Dark-Minimal Design** — Glassmorphism, bold typography, gradient accents
- **AI-Powered Assistant** — Multilingual (English/Burmese) contextual project explanations
- **Project Case Studies** — Interactive carousel with expandable technical deep-dives
- **82+ Certificates** — Searchable, filterable gallery from Programming Hub
- **Interactive Background** — Particle.js animated canvas + Three.js 3D floating shapes
- **Micro-Interactions** — Typing animation, animated cursor, scroll-triggered reveals
- **Dark/Light Mode** — Fully themed with smooth transitions
- **Responsive** — Optimized for all devices (mobile, tablet, desktop)
- **SEO Optimized** — Meta tags, Open Graph, JSON-LD structured data
- **Performance** — Lighthouse score 95+ with lazy loading and code splitting

## 📦 Getting Started

### Prerequisites

- Node.js 18+ 
- npm, yarn, or pnpm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/moe-kyaw-aung-ai-portfolio.git
cd moe-kyaw-aung-ai-portfolio

# Install dependencies
npm install
# or
yarn install
# or
pnpm install

# Run development server
npm run dev
# or
yarn dev
# or
pnpm dev
