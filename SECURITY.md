# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x (Current) | ✅ Fully supported |

## Reporting a Vulnerability

If you discover a security vulnerability in this portfolio, please report it privately.

**Do not** disclose the vulnerability publicly until it has been addressed.

### How to Report

- **Email:** moekyawaung@programmer.net
- **PGP Key:** Available at `https://moekyawaung.dev/.well-known/pgpkey.txt`

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

### Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial assessment:** Within 5 business days
- **Fix release:** Within 14 business days (depending on severity)

## Security Measures

This portfolio implements:
- HTTPS enforced via Cloudflare
- Security headers (CSP, X-Frame-Options, etc.)
- Input sanitization
- No sensitive data exposure
- Regular dependency updates via Dependabot
