# Contributing to Moe Kyaw Aung Portfolio

Thank you for considering contributing! This is a personal portfolio, but bug reports and accessibility improvements are welcome.

## How to Contribute

### Reporting Bugs

1. Check if the bug has already been reported in [Issues](https://github.com/Dev-moe-kyawaung/moe-kyaw-aung-portfolio/issues)
2. If not, create a new issue with:
   - Clear description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots (if applicable)
   - Browser/device information

### Suggesting Enhancements

1. Open an issue with the label `enhancement`
2. Describe the improvement
3. Explain why it would be beneficial

### Pull Requests

1. Fork the repository
2. Create a new branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit: `git commit -m 'Add feature description'`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## Code Style

- Follow the existing code style
- Use TypeScript
- Run `npm run lint` before committing
- Keep components modular and reusable
